# Web Development II - Assessment 1

This repository contains my work for Web Development II Assessment 1.

## Task 1 - Layout in React

A React website based on the Erased Tapes design.

The page includes a header, article, image gallery, author section, comments and footer.

## Task 2 - Responsive Layouts

A responsive React website called watch.it.

The website displays movie cards and uses CSS media queries to adapt the layout for mobile, tablet and desktop screens.

## How to Run the Projects

Both projects were created using React and Vite.

To run either project:

1. Open the task's react-app folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.
